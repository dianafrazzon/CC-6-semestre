# Sistema Percepção Humana

Computadores trabalham aliados as nossas capacidades de percepção, como o sistema visual, que exige uma curta quantidade de tempo para reagir a estímulos apresentados. Importante ter em mente que o Sistema de Percepção Humana associa significado à informação, seja este significado pretendido ou não pretendido.

Mudanças na interface atraem nossa atenção (estímulos), quanto mais estímulos apresentados mais exige do usuário, assim mais esforço é realizado pelo usuário com risco de gerar canseira/esgotamento. Estímulos, por exemplo, são:  luzes, sons, movimentos, cores, novidades.

Nossos sistemas sensoriais/sentidos dão sentido ao mundo, todos os dados sensoriais são usados para construir uma interpretação consistente do mundo. 

## Ambiguidade

Conflito de interpretações, quando o mesmo cenário pode ser interpretado de diferentes formas. Esse fenômeno é gerado ou pela falta de informações ou pelo excesso de informações, para que o processo seja aparente é necessário que as quantidades de informações sejam suficientes.

## Conclusões 

- Perceber vale mais do que apenas ver. 

Interfaces gráficas oferecem facilidades ao usuário para manipulação do computador mas exigem mais processamento perceptivo. O projetista deve estar consciente das possibilidades e restrições do usuário, sempre considerando a perspectiva do usuário.

A interface gira em torno do Processador de Informações Humano.
